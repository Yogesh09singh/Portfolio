# Yogesh Singh — Personal Portfolio Website

An award-winning, Apple-inspired personal portfolio website for **Yogesh Singh** (Full-Stack Developer & Machine Learning Enthusiast).

Built with React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Lenis Smooth Scroll.

---

## 🚀 Live Features & Highlights

- **Apple Dark Aesthetic**: Dark luxury palette (`#050816`, `#0F172A`, `#6366F1`, `#06B6D4`, `#A855F7`).
- **Typography**: Google Fonts — Sora (Headings), Inter (Body), JetBrains Mono (Code/Badges).
- **Smooth Animations**: Lenis smooth scroll, Framer Motion staggered reveals, interactive canvas particles, and custom follower cursor.
- **Project Showcase**: Rich interactive project cards for:
  1. *AI-Based Multimodal Search Engine* (Text, Voice, Image)
  2. *Real-Time Voice Recognition System* (<1s Latency, 92%+ Accuracy)
  3. *GitHub Repository Intelligence Dashboard* (Gemini AI, Docker, ReportLab PDF Export)
- **Experience Timeline**: Detailed internships at Prodigy Infotech & Codsoft with metrics.
- **Certifications**: AWS Academy Cloud Architecting, Cisco Network Technician, Infosys Java, HackerRank SQL.
- **Interactive Resume Modal**: Inline resume view with 1-click text/markdown download.
- **Vercel Deployment Ready**: Zero-config deployment with `vercel.json` rewrite rules.

---

## 🛠️ Tech Stack

- **Core**: React 18, Vite 5, TypeScript 5
- **Styling**: Tailwind CSS v3, Custom Glassmorphism, CSS Modules
- **Animations**: Framer Motion 11, GSAP 3, Lenis Smooth Scroll
- **Icons**: Lucide React, React Icons
- **Utility**: Canvas Confetti, Clsx, Tailwind Merge

## 💻 Local Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Local Dev Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Production Build**:
   ```bash
   npm run build
   ```

---

## 🌐 Deploying to Vercel

1. Push your repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your repository.
4. Keep framework setting as **Vite** and default build command (`npm run build`).
5. Click **Deploy**.
